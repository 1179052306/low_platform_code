## 3. 核心数据模型（TypeScript 类型定义）

```typescript
// src/types/warehouse-3d.ts

/** 仓库 */
interface Warehouse {
  id: string
  code: string
  name: string
  length: number      // X 方向长度（米）
  width: number       // Z 方向宽度（米）
  height: number      // Y 方向高度（米）
  areas: WarehouseArea[]
  obstacles: Obstacle[]
  channels: Channel[]
}

/** 库区 */
interface WarehouseArea {
  id: string
  code: string
  name: string
  areaType: 'storage' | 'picking' | 'staging' | 'receiving' | 'shipping'
  x: number           // 区域起点 X（米，仓库局部坐标）
  z: number           // 区域起点 Z
  length: number      // 区域长度 X
  width: number       // 区域宽度 Z
  racks: Rack[]
}

/** 货架 */
interface Rack {
  id: string
  code: string
  x: number
  z: number
  length: number
  width: number
  levels: number      // 层数
  baysPerLevel: number // 每层货格数
  orientation: 'x' | 'z'  // 货架长轴方向
  locations: Location[]
}

/** 库位 */
interface Location {
  id: string
  code: string        // 如 A-01-02-03
  rackId: string
  level: number       // 层（1-based）
  bay: number         // 货格（1-based）
  x: number
  y: number
  z: number
  size: { x: number; y: number; z: number }
  status: LocationStatus
  utilization: number // 0-1 占用率
  productCode?: string
  updateTime?: string
}

/** 库位状态 */
type LocationStatus =
  | 'empty'       // 空
  | 'partial'     // 部分占用
  | 'full'        // 满
  | 'locked'      // 锁定
  | 'reserved'    // 预留
  | 'disabled'    // 禁用
  | 'error'       // 异常

/** 静态障碍物 */
interface Obstacle {
  id: string
  obstacleType: 'pillar' | 'wall' | 'door' | 'column'
  x: number
  z: number
  length: number
  width: number
  height: number
  rotation: number    // Y 轴旋转（弧度）
}

/** 通道 */
interface Channel {
  id: string
  channelType: 'main' | 'sub' | 'fire'
  path: { x: number; z: number }[]  // 通道路径点
  width: number
  bidirectional: boolean
}

/** 拣货路径 */
interface PickingPath {
  id: string
  startPoint: { x: number; z: number }
  endPoint: { x: number; z: number }
  waypoints: { x: number; z: number; locationId?: string }[]
  totalDistance: number
  algorithm: 'nearest' | 's-shape' | 'optimal'
}

/** 版本快照 */
interface LayoutSnapshot {
  id: string
  version: number
  warehouseId: string
  snapshotTime: string
  operator: string
  description: string
  data: Warehouse          // 完整布局数据
  changeLog?: string       // 变更说明
}

/** 编辑锁 */
interface EditLock {
  warehouseId: string
  lockedBy: string         // 用户 ID
  lockedByName: string     // 用户名
  lockedAt: string         // ISO 时间
  expiresAt: string        // 过期时间
}
```

## 4. 核心模块设计

### 4.1 SceneContainer.vue — 画布容器

职责：
- 挂载 `<canvas>` 元素，初始化 `WarehouseRenderer`
- 监听容器 resize，调用 `renderer.onResize()`
- 组件卸载时释放 WebGL 资源（`dispose()`）
- 提供 slot 供 UI 面板叠加（工具栏/图例/版本面板）

```vue
<template>
  <div class="warehouse-3d-container" ref="containerRef">
    <canvas ref="canvasRef" class="warehouse-3d-canvas" />
    <div class="warehouse-3d-overlay">
      <slot name="toolbar" />
      <slot name="legend" />
      <slot name="panel" />
    </div>
  </div>
</template>
```

### 4.2 WarehouseRenderer.ts — 3D 渲染引擎

核心类，管理整个 Three.js 场景生命周期。

```typescript
class WarehouseRenderer {
  scene: THREE.Scene
  camera: THREE.PerspectiveCamera | THREE.OrthographicCamera
  renderer: THREE.WebGLRenderer
  controls: OrbitControls
  
  layoutBuilder: LayoutBuilder
  obstacleBuilder: ObstacleBuilder
  pathRenderer: PathRenderer
  selectionManager: SelectionManager
  editController: EditController
  
  // 性能优化：InstancedMesh 渲染库位
  locationMesh: THREE.InstancedMesh  // 万级库位单次 draw call
  
  init(canvas: HTMLCanvasElement): void
  loadLayout(warehouse: Warehouse): void
  onResize(): void
  setViewMode(mode: 'perspective' | 'top' | 'side' | 'front'): void
  setEditMode(enabled: boolean): void
  fitToView(): void
  dispose(): void
}
```

**万级库位性能策略：**
- 库位用 `InstancedMesh`（1 个 geometry + 1 个 material，N 个 instance matrix）
- 库位状态颜色用 `instanceColor` 属性，不创建额外 material
- 仅库位有交互需求时启用 raycaster，且限制拾取范围（视锥内）
- 选中高亮用 `OutlinePass`（EffectComposer）或 emissive 颜色变化，不克隆几何体
- 远距离自动降级：相机距离 > 阈值时隐藏库位边线/标签

### 4.3 LayoutBuilder.ts — 布局构建器

职责：将 `Warehouse` 数据构建为 Three.js 对象树。

```
Scene
  └─ WarehouseGroup
       ├─ FloorMesh（地面网格）
       ├─ AreaGroups[]
       │    ├─ AreaBoundaryMesh（库区边界线框）
       │    └─ RackGroups[]
       │         ├─ RackFrameMesh（货架框架）
       │         └─ LocationInstancedMesh（库位 InstancedMesh）
       ├─ ObstacleGroups[]（柱/墙/门）
       └─ ChannelLines[]（通道线）
```

- 地面：`PlaneGeometry` + 网格 `GridHelper`（可切换显隐）
- 库区边界：`EdgesGeometry` + `LineSegments`，扁平化线框风格
- 货架框架：`BoxGeometry` 立柱 + 横梁，合并为静态 `BufferGeometry`
- 库位：`InstancedMesh`，每个 instance 的 matrix 决定位置/缩放，color 决定状态色

### 4.4 SelectionManager.ts — 选中管理

- `Raycaster` 拾取：鼠标点击 → 射线检测 → 命中 instanceId → 高亮
- 高亮方式：修改命中 instance 的 emissive 颜色 + 显示边框 `BoxHelper`
- 多选：Shift+点击追加，Ctrl+点击切换
- 框选：鼠标拖拽矩形 → 屏幕空间 AABB → 视锥剔除 + raycaster 逐个检测
- 选中事件回调：`onSelect(locations: Location[])`

### 4.5 EditController.ts — 反向编辑控制器

在编辑模式下，直接在 3D 场景中拖拽/缩放/删除对象，变更同步回 `layoutStore`。

| 操作 | 对象 | 交互 | 回写 |
|---|---|---|---|
| 拖拽移动 | 库区/货架/障碍物 | 鼠标按下→拖动→释放 | 更新 x/z |
| 缩放 | 库区/货架 | 选中+拖拽边手柄 | 更新 length/width |
| 删除 | 库位/货架/障碍物 | 选中+Delete 键 | 从布局数据移除 |
| 新增 | 库位/障碍物 | 工具栏选择类型+点击放置 | 追加到布局数据 |

**拖拽实现：**
- `DragControls`（Three.js 内置）或自实现 `raycaster + plane intersection`
- 拖拽平面：Y=0 地面平面（平库只在 XZ 平面移动）
- 实时更新：拖拽中每帧更新对象 position + emit `preview-change`
- 释放确认：释放时 emit `edit-commit`，触发 `layoutStore` 更新 + 标记未保存

**缩放手柄：**
- 选中对象后显示 8 个边角手柄（小立方体）
- 拖拽手柄 → 计算 delta → 更新对象 size → 重建 geometry

### 4.6 PathRenderer.ts — 拣货路径渲染

- 路径线：`TubeGeometry` 或 `Line` 沿 waypoint 连接
- 路径动画：沿路径移动的标记球（`Mesh + tween`）
- 起终点标记：绿色起点 / 红色终点图标
- 多路径对比：不同颜色区分算法（nearest/s-shape/optimal）

### 4.7 DegradationManager.ts — 异常降级

| 异常 | 降级策略 |
|---|---|
| WebGL 不可用 | 显示 2D 平面俯视图（Canvas 2D fallback） |
| 库位数 > 50000 | 分区域加载，远处库位合并为低精度方块 |
| 渲染 FPS < 15 持续 3s | 自动降低渲染精度（关闭阴影/边线/抗锯齿） |
| WebSocket 断连 | 降级为定时轮询（每 5s 拉取库位状态） |
| 布局数据加载超时 | 显示骨架屏 + 重试按钮 |
| 内存 > 阈值 | 释放非可视区域 geometry（分区域卸载） |

### 4.8 CameraController.ts — 相机控制器

- 视角模式：`perspective`（透视）/ `top`（正交俯视）/ `side`（正交侧视）/ `front`（正交前视）
- `OrbitControls`：左键旋转 / 右键平移 / 滚轮缩放
- `fitToView(target?)`：计算目标包围盒 → 调整相机位置和 fov 使其填满视口
- 编辑模式下锁定旋转（只允许平移+缩放），避免 3D 空间编辑困难

## 7. WebSocket 实时推送

```typescript

interface WsMessage {
  type: 'locationStatus' | 'lockChanged' | 'layoutUpdated' | 'snapshotCreated'
  warehouseId: string
  payload: unknown

/** 库位状态变更推送 */
interface LocationStatusUpdate {
  locationId: string
  status: LocationStatus
  utilization: number
  productCode?: string
  updateTime: string
}
```

- 连接地址：`ws://{host}/ws/warehouse-3d/{warehouseId}`
- 自动重连：断连后 3s/5s/10s 指数退避重连，最多 5 次
- 心跳：每 30s 发送 ping，超 60s 无 pong 则判定断连
- 消息分发：按 type 分发到对应 store 更新

## 10. 性能优化策略

| 场景 | 策略 |
|---|---|
| 万级库位渲染 | InstancedMesh 单次 draw call |
| 库位状态更新 | 仅更新 instanceColor + instanceMatrix，不重建 geometry |
| 视锥剔除 | Three.js 内置 frustumCulled = true |
| 远距离降级 | 相机距离 > 阈值时隐藏边线/标签/阴影 |
| 分区域加载 | 大仓库按库区分组，仅渲染可视区域 + 邻近区域 |
| 内存控制 | 切换仓库时 dispose 旧场景所有 geometry/material/texture |
| 渲染循环 | requestAnimationFrame + 视脏标记（无变更时不重渲染） |
| Raycaster 优化 | 仅编辑模式/点击时启用，拾取限制在视锥内 |

## 11. 异常降级详细方案

### 11.1 WebGL 不可用

检测 `canvas.getContext('webgl')` 返回 null 时：
1. 隐藏 3D 画布
2. 显示 2D 俯视图（Canvas 2D API 绘制平面布局）
3. 顶部提示条："当前环境不支持 WebGL，已降级为 2D 视图"

### 11.2 渲染崩溃

监听 `renderer.debug.onShaderError` / `window.onerror`：
1. 记录错误日志
2. 显示重试按钮
3. 自动降级渲染精度后重试

### 11.3 数据超限

库位数 > 50000 时：
1. 提示："库位数量超过 50000，已启用分区域加载模式"
2. 仅渲染当前视角可视库区

## 13. 与现有低代码平台的关系

- **路由集成**：作为独立视图 `Warehouse3DView` 注册到现有路由，通过菜单管理挂载
- **UI 风格**：复用 Element Plus 组件，扁平化风格，el-splitter 布局，无圆角卡片
- **权限**：复用现有 RBAC 体系，通过菜单权限控制 3D 可视化入口
- **国际化**：复用现有多语言方案（后台加载语言资源），3D 面板文案走同一套
- **独立模块**：3D 渲染逻辑与低代码设计器/渲染器完全独立，不修改现有 designer/renderer 代码
- **后端**：新增独立 Controller/Service，不侵入现有 CRUD 引擎
