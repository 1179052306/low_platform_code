## 2. 需增强的部分

### 2.1 流程类型区分（小改）

在 `WorkflowDesignerView.vue` 中，根据 `workflowType` 区分业务流和审批流的展示：

- **业务流（bizFlow）**：工具箱显示全部8种节点类型
- **审批流（approvalFlow）**：工具箱只显示 start/end/userTask（简化模式）

**改动文件**：`FlowNodePalette.vue` — 根据 `workflowType` 过滤可拖拽的节点类型

### 2.2 单据节点操作类型改为下拉选择（小改）

当前 `billTask` 的操作类型是自由输入框（`placeholder="如: submit/approve/reject"`），应改为下拉选择，选项来自该单据的可用操作。

**改动文件**：`FlowPropertyPanel.vue:217-223` — `billAction` 从 `ElInput` 改为 `ElSelect`，选项根据 `billCode` 动态加载

### 2.3 网关分支条件配置增强（小改）

当前网关只有 `conditionExpr` 单个条件表达式，金蝶的网关支持多分支配置（每个分支有独立的条件+名称）。类型定义中已有 `branches?: { id, condition, name }[]`，但属性面板未展示分支列表编辑。

**改动文件**：`FlowPropertyPanel.vue` — gateway 节点增加分支列表编辑（分支名称 + 条件表达式 + 增删按钮）

### 2.4 连线条件标注编辑（小改）

当前连线可在属性面板中编辑 `label`/`condition`，但入口不够明显。应在选中连线时，属性面板显示连线编辑（条件表达式 + 标签）。

**改动文件**：`FlowPropertyPanel.vue` — 当 `selectedTransition` 不为空时，显示连线编辑面板

### 2.5 校验结果展示（小改）

`store/workflow.ts` 已有 `validateWorkflow`，但 `WorkflowDesignerView.vue` 中校验按钮的结果展示需要增强——以列表形式展示所有校验错误，而非简单 alert。

**改动文件**：`WorkflowDesignerView.vue` — 校验结果用 ElDialog 或 ElMessage 列表展示
