## 追加（同日 · 第三笔）DbValue 方言机制重构（可扩展）
- 用户诉求：DbValue 里 31 个方法每段都是 "0"~"4" 五段 if-else 写死，加一个数据库要改 30+ 处 → 做成可扩展。
- 方案（策略模式 + Spring 自动注册）：
  - 新建 `com/server/db/DbType.java` 常量（MYSQL"0"/ORACLE"1"/SQLSERVER"2"/POSTGRESQL"3"/DM"4"），终结魔法值（其他 ~100 处魔法值替换留待后续）。
  - `DbValueServer` 接口：唯一抽象方法 `dbType()`；原有 24 个方法全部 default 化（返回 "" = 方言未启用，与历史 MySQL/SQLServer 空分支一致）；下沉 5 个原 DbValue 内联方法：xmlSql/xmlValue/selectDummy(原 dual)/decimalPoint(原 getDecimalPoint)/resetSeqSql。
  - 新建 `OracleLikeVal` 抽象基类：承载 Oracle 系全部公共实现（dbHelp 注入、xmlSql 大写、FROM DUAL、SETVAL 重置序列等）；`OracleVal`（dbType=ORACLE）与 `DmVal`（dbType=DM，仅覆盖 getTableDescription）变薄子类。未来金仓等 Oracle 系直接继承。
  - `PostgreSqlVal`：加 dbType=POSTGRESQL + xmlSql 小写/xmlValue toLowerCase/decimalPoint "x::float"/resetSeqSql PG setval 覆盖。
  - `SqlServeVal` 保持非 bean 占位（多数方法返回 null，加注释提醒补全后再 @Service），补了 dbType()=SQLSERVER。
  - 新建 `EmptyDbValueServer` 兜底方言（dbType="unknown"），DbValue 未注册类型走它；兼作新方言空白模板。
  - `DbValue` 1079→约 300 行：`@Autowired List<DbValueServer>` 启动注册进 Map（重复 dbType 告警），31 个公共方法全部一行 `dialect(dbName).xxx()` 委托；公共 API 签名（含 throws）不变，调用方零改动。
- 行为差异（有意修复，仅影响 MySQL/SQLServer 空分支）：XmlValue 从返回 "" 改为原样返回；getDecimalPoint 从 "" 改为 default ROUND。Oracle/PG/DM 行为逐方法与旧代码一致。
- 编译 `-f bcd-wms-db/pom.xml compile -o` BUILD SUCCESS。新增数据库步骤 = 复制 EmptyDbValueServer → 补 dbType + 差异方法 → @Service，零侵入。

## DbValue 方言扩展机制重构（第二轮，BUILD SUCCESS + 20 单测全过）
- **策略模式 + Spring 自动注册**：`DbType` 常量（0MySQL/1Oracle/2SQLServer/3PG/4达梦）；`DbValueServer` 接口唯一必实现 `dbType()`，其余 default；`OracleLikeVal` 抽象基类（Oracle/达梦共用）；`DbValue` 1079→约300 行注册表分发，零 if-else。
- **fail-fast（第三轮确认落地）**：`DbValue.registerDialects` 重复 dbType 启动抛 IllegalStateException；`dialect()` 未注册类型/类型解析为 null 运行期抛明确异常；`dialect` 改 public 供其他分发器复用；`EmptyDbValueServer` 仅作新方言空白模板（不再兜底）。
- **残留反模式收编（15 处 if-else 清零）**：
  - `DbBatchRes`：分支下沉为 `DbValueServer.batchResult(int[])`（Oracle 系 -2/1 计数，PG 仅 1 计数），一行委托；
  - `DbConvertSql`：骨架化——字面量保护(IndexOfSting) → `convertKeywordCase`/`nullifToNvl`/`fixDeleteFrom` 方言转换 → UPDATE 别名清理；`splitStrSql`/`deleteStrSql` 委托 `strSplitFilter`/`deleteFromFragment`；
  - `DbTableXml`：注册表分发，`DbTableXmlServer` 加 `dbType()`，OracleXmlMange/PgXmlMange/DmXmlMange 各自声明；未注册类型保持返回空结果 + warn（XML 元数据为辅助功能，不中断主流程）；
  - `GetTableData`：新建 `gridpage/GetTableServer` 接口（getData/getReportData/dbType），OracleGetTable/DmGetTable/PostgresSqlGetTable 实现，注册表分发，重复注册启动抛异常。
- **顺带修复 4 个隐藏 bug**（均为原实现 latent bug，现因逻辑真正生效而暴露）：
  1. `removeUpdateAlias` 返回值被丢弃（从未生效）→ 已赋值回 SqlStr；
  2. `contains("update")` 小写判断对 Oracle 大写 SQL 永不命中 → 改 `toLowerCase(Locale.ROOT)`；
  3. `removeUpdateAlias` 拼接 "SET子句+WHERE" 无空格（产生 "B=2WHERE" 非法 SQL）→ WHERE 前补空格；
  4. `log.info("执行SQL:")` 每条 SQL 都打 → 降 log.debug。
- **单测保护网（db 模块首个测试）**：`bcd-wms-db/src/test/java` 下 4 个测试类 20 个用例：DialectRegistryTest（注册/分发/重复/未注册 fail-fast）、DialectSqlSnapshotTest（方言纯 SQL 快照）、DbConvertSqlTest（转换/片段/批量结果集成）、StubDbConfig+TestFields 工具。
